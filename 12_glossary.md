# Glosario

## Producto

Elemento o artículo que puede ser adquirido por la organización mediante el proceso de compras.

## Proveedor

Persona o empresa encargada de suministrar productos o servicios a la organización.

## Orden de Compra

Documento generado por el sistema para solicitar productos o servicios a un proveedor.

## Compra

Proceso mediante el cual la empresa adquiere productos o servicios necesarios para su operación.

## Recepción de Mercancía

Proceso donde se registra la llegada de los productos adquiridos mediante una orden de compra.

## Inventario

Conjunto de productos almacenados y disponibles para la organización.

## Usuario

Persona autorizada para utilizar el sistema ERP según sus permisos asignados.

## ERP

Sistema de planificación de recursos empresariales que integra diferentes procesos de la organización.
