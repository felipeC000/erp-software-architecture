# Vista de Ejecución

## Escenario: Registrar un Producto

El escenario seleccionado corresponde al registro de un producto dentro del Módulo de Compras.

<img width="892" height="398" alt="image" src="https://github.com/user-attachments/assets/126612b5-cfb0-4177-8c6c-44208fd8a57e" />

## Flujo del proceso

1. El usuario ingresa al módulo de compras.
2. Selecciona la opción para registrar un nuevo producto.
3. El sistema muestra el formulario de registro.
4. El usuario completa la información del producto.
5. El frontend envía los datos al backend.
6. El backend valida la información recibida.
7. Si los datos son correctos, se almacena el producto en PostgreSQL.
8. El sistema confirma al usuario que el producto fue registrado correctamente.
